# cadastro_jonathan

Projeto de cadastro moderno em HTML, CSS e JavaScript.

## Como executar

1. Abra o arquivo `index.html` diretamente no navegador, ou
2. Rode um servidor simples na pasta do projeto:

```bash
python -m http.server 8000
```

Depois acesse: `http://localhost:8000`

## Estrutura

- `index.html` — estrutura da página
- `style.css` — estilos da interface
- `script.js` — validação do formulário
